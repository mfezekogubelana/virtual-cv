# virtual-cv

## Overview

This project is my personal website developed as part of my university portfolio assignment. It serves as an online curriculum vitae showcasing my education, technical skills, academic projects, and contact information.

The website showcases:

- About Me
- Skills
- Certifications
- Projects
- Contact Information
- Downloadable CV

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design
- Downloadable CV
- Academic Projects
- Viewable certificates
- Skills section
- Contact Information
- Links to GitHub and LinkedIn profiles
